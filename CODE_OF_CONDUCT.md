# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, welcome newcomers and people writing in a second language, and
keep criticism about the work, not the person. Harassment, insults and personal attacks aren't tolerated in issues,
pull requests or anywhere else the project lives.

To report a problem, contact the maintainer privately through GitHub (a [private security advisory](https://github.com/ybkjs/tinyfactory/security/advisories/new)
works for conduct reports too). Reports are handled confidentially, and the maintainer may remove content or block
accounts that break these rules.
